# مِداد — تطبيق محاسبي عربي مستقل

[![اختبارات وبناء](https://github.com/22kdx/midad-erp/actions/workflows/tests.yml/badge.svg)](https://github.com/22kdx/midad-erp/actions/workflows/tests.yml)

> **تحميل التطبيق:** [midad-1.0.0-debug.apk](https://github.com/22kdx/midad-erp/releases/latest) — أندرويد ٨ (API 26) وأحدث.
> البناء يجري ويُختبر تلقائياً على GitHub Actions: ١٥٢ اختبار نواة + APK جاهز في كل دفعة.


تطبيق أندرويد محاسبي كامل، **مستقل تماماً**: لا خادم، لا ربط بأي مستودع، كل البيانات على الجهاز.

```
midad-app/
├── app/src/main/java/com/example/midad/
│   ├── core/          ← نواة المحاسبة (منطق نقي · ٢٧ ملفاً · ١٥٢ اختباراً)
│   ├── data/local/    ← Room v4: ٢٥ جدولاً + DAO + RoomErpStore
│   ├── ui/theme/      ← ثيم مِداد (ألوان وتوكنز مطابقة للتصميم)
│   ├── ui/components/ ← مكوّنات مشتركة (بطاقات · إحصاءات · عناوين)
│   ├── ui/screens/    ← ١١ شاشة أعلى الشاشة (تبويبات أفقية)
│   └── ui/MidadViewModel.kt
├── build.sh           ← تشغيل اختبارات النواة بلا Android SDK
└── settings.gradle.kts / build.gradle.kts / app/build.gradle.kts
```

## مبادئ البناء

1. **الشاشة لا تبني قيداً أبداً.** كل عملية تجارية تمر من `PostingService` → `JournalKernel.validate`.
2. **المُرحّل لا يُعدَّل ولا يُحذف** — التصحيح بقيد عكسي.
3. **النقود أعداد صحيحة** (`Long` بالوحدة الصغرى) لا `Double`.
4. **التكلفة حقيقية** — متوسط مرجّح متحرك، والربح محسوب لا مخترع.
5. **الميزان متوازن دائماً** — يُفحص في كل قيد وبالاختبارات (١٥٢ اختباراً).

## التشغيل

### ١) اختبارات النواة (بلا Android)
```bash
./build.sh          # ١٥٢ اختباراً · يجب أن تكون كلها ناجحة
```

### ٢) بناء التطبيق
افتح المجلد في **Android Studio** (Ladybug أو أحدث) ثم Run.
أو:
```bash
gradle wrapper --gradle-version 8.9
./gradlew assembleDebug
```

**الخطوط:** يستخدم الثيم خطاً عربياً نظامياً مع بديل احتياطي؛ لإضافة IBM Plex Sans Arabic
ضع ملفات TTF في `app/src/main/res/font/` وحدّث `Theme.kt`.

## البنية الداخلية

```
core/  Money · Model · Kernel · Costing · Chart · Rules · Fx · Store · PostingService
       Operations · Statements · Tafqeet · Parties · Documents · Printing
       Auth · Backup · Extras · DataPort
```

- `JournalKernel` — الدالة الوحيدة التي تُنتج قيداً صالحاً.
- `PostingService` — يربط الشاشة بالمخزن والكيرنل ويرقّم ويُدقّق.
- `ErpStore` — واجهة تخزين تفصل النواة عن Room (تسمح بخادم لاحقاً بلا إعادة كتابة).
- `DocEngine` / `DocPosting` — إجماليات المستند وسطور قيده.
- `Printing` — قالب طباعة مستقل مع التفقيط.

## القيود الحالية (شفافية)

- الواجهات لا تُترجَم في هذه البيئة (لا Android SDK) — التحقق بالمراجعة والبنية.
- بلا تعريب كامل للأرقام العربية الهندية في الحقول الرقمية (يقبل اللاتينية فقط).
- المزامنة السحابية غير منفّذة بحكم قرار التطبيق المنفرد.
